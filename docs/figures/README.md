# Final Editable Vector Figures

These are the current figures used by the final Lazyshu technical report.

- `figure_1_modalities`: synthetic overview of six modality groups
- `figure_2_validation`: two-fold development and full-data refit protocol
- `figure_3_architecture`: multimodal encoder, internal adapters, and decoder
- `figure_4_routing`: V127 external routing and V71 internal-gate distinction
- `figure_5_results_budget`: development trajectory and storage accounting

Each figure is provided as editable SVG, publication PDF, and PNG preview.
`draw_figures.py` regenerates all formats with Python, NumPy, Matplotlib, and
Pillow. The diagrams contain no competition sample.
