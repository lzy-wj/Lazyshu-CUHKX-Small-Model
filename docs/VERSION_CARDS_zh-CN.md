# Lazyshu 关键代数记忆卡

> 你不需要背 197 个版本。建议掌握 **10 个核心代数 + 5 个辅助代数 + 3 个反例代数**。

## 1. 一条记忆口诀

**一二三打基础，二四立锚点；五二五七做压缩，七一做门控；八九一零四保视觉，一一四配同人；一二七定路由，一六四做保险，一六六提醒别迷信本地。**

对应版本：

`V1 → V2 → V3 → V24 → V52 → V57 → V71 → V89 → V104 → V114 → V127 → V164`

反例：`V96 / V160 / V166`

---

## 2. 必须背下来的 10 个核心版本

### 卡 1：V1 —— 真实起点

- **关键词**：自建六模态 baseline。
- **改进前提**：先跑通数据、验证、训练、推理和打包。
- **成绩**：`53.94%`。
- **一句话**：简单把六模态放在一起，并不会自动得到强泛化。

### 卡 2：V2 —— 输入稳定化

- **关键词**：人物裁剪、IR 增强、世界坐标 IMU。
- **成绩**：`63.45%`。
- **相对 V1**：`+9.51` 个百分点。
- **一句话**：先消除背景和佩戴方向噪声，再谈更大模型。

### 卡 3：V3 —— 时空视觉跃迁

- **关键词**：X3D-S 3D 视频编码器。
- **成绩**：`70.52%`。
- **一句话**：日常行为需要时空特征，2D 外观特征不够。

### 卡 4：V24 —— 部署锚点

- **关键词**：五源 full-data parameter soup、INT8、伪标签适配。
- **本地**：`1168/1357 = 86.07%`。
- **Public**：`0.91044`。
- **一句话**：V24 是后续残差、Adapter 和保护规则共同依赖的基础 incumbent。

### 卡 5：V52 —— 小残差替代大集成

- **关键词**：domain-conditioned logit residual。
- **本地**：`1193/1357 = 87.91%`。
- **规模**：测试侧 `9,720` 个 residual 参数。
- **一句话**：不再重跑大模型，只学习不同 domain 中怎样重新排序类别证据。

### 卡 6：V57 —— 序列教师压缩

- **关键词**：round Transformer distillation。
- **本地**：`1195/1357 = 88.06%`。
- **规模**：`92,392` 参数，约 `192 KB`。
- **一句话**：按采集轮次学习序列修正，并精确复现复杂教师决策。

### 卡 7：V114 —— 同人跨环境适配

- **关键词**：paired-person adapter、anchored fusion。
- **融合**：`60%` paired adapter + `40%` protected V104。
- **本地**：`1180/1357`。
- **一句话**：有同一个人在另一环境的标签时，只训练小 Adapter，并保留原系统防止过拟合。

### 卡 8：V127 —— 最终主系统

- **关键词**：supervision-aware deterministic routing。
- **路由**：有同人 source 走 V114；否则走 V57 anchor；source 不支持时回退 V24。
- **本地**：`1205/1357 = 88.80%`。
- **Public / Private**：`0.92039 / 0.91176`。
- **结果**：私榜第 4。
- **一句话**：最终最重要的创新不是更大网络，而是按合法监督可用性选择最可靠专家。

### 卡 9：V164 —— 最终次提交

- **关键词**：evidence-gated Radar challenger。
- **规则**：challenger rank `<=2`，incumbent rank `>=3` 才替换。
- **本地**：`1213/1357 = 89.39%`。
- **Public / Private**：`0.91044 / 0.90686`。
- **一句话**：结构先验只能提出候选，最终必须服从原始神经证据。

### 卡 10：V166 —— 本地最高但不能选

- **关键词**：repeated-transition consensus。
- **本地**：`1226/1357 = 90.35%`，项目最高。
- **Public**：`0.88557`。
- **一句话**：本地采集脚本规律无法稳定迁移，因此最终拒绝。

## 3. 建议记住的 5 个辅助版本

### V23 —— 统一主干与训练配方

- 共享 R(2+1)D + Skeleton temporal CNN + IMU Conv/BiLSTM + masked Transformer。
- 它是 V24 full-data refit 的训练与工程基础。

### V71 —— 开发阶段 FiLM 学生

- 本地 `1201/1357 = 88.50%`。
- FiLM correction 只在开发定义的 domain 2 打开。
- **易错点**：最终 V127/V164 中，domain-2 样本走 V114，无配对样本 gate 关闭并等于 V57；所以 V71 FiLM 不直接改变最终标签。

### V89 —— 多尺度锚点

- 128/160 两个 head delta 固定等权平均。
- 本地 `1170/1357`。
- 是后续 protected Adapter 的视觉基线。

### V104 —— 受保护且按域开启的 Adapter

- 只在双折都有收益的 domain 开启 Adapter。
- 本地 `1175/1357`。
- 是 V114 40% protected evidence 的来源。

### V113 —— V114 的直接前身

- paired-person adapter + equal fusion。
- decoded `1176/1357`。
- V114 把它改为更保守的 60/40 anchored fusion，提升到 1180。

## 4. 三个必须会讲的反例

### V96：更大参数量不等于更强泛化

- 三视觉分支只共享低层，解冻高层后暴露 `117.2M–178.4M` 可训练参数。
- held-out 用户迅速遗忘。
- 推导：容量不是主要瓶颈，适配自由度才是风险。

### V160：结构规则可能学到采集脚本

- 本地从 V127 的 1205 提升到 1222。
- Public 却跌到 `0.84079`。
- 推导：Radar 时间分组很强，但不能无条件覆盖 clip-level evidence。

### V166：双折稳定也不是最终真理

- 两折、逐用户、60 个压力视图都没有新增错误。
- Public 仍跌到 `0.88557`。
- 推导：开发折和压力测试仍共享训练数据的生成机制。

## 6. 一分钟版本史

> 我们从 53.94% 的自建六模态 baseline 开始。V2 通过人物裁剪、IR 增强和世界坐标 IMU 提升到 63.45%；V3 使用 X3D-S 时空视觉编码提升到 70.52%。随后统一为共享 R(2+1)D、Skeleton temporal CNN、IMU BiLSTM 和 masked Transformer，并在 V24 用五源参数汤、INT8 与伪标签适配达到 86.07%。V52 和 V57 把复杂教师压缩为小型 logit residual 与 round Transformer。后期我们发现大规模解冻会破坏跨用户泛化，因此改用受保护 Adapter；V114 利用同一自然人的跨环境标签，V127 再按监督是否可用确定性路由，最终私榜 91.176%、第 4。Radar 结构解码本地很强，但 V160/V166 线上退化，所以只保留由神经 posterior 门控的 V164 作为第二提交。

## 7. 三分钟版本史提纲

### 第一段：任务与验证

- 40 类、六模态、3,036/405、100 MB。
- 随机 clip 切分会泄漏人员与环境，所以使用两个 user-isolated development folds。
- 主要瓶颈是 conditional distribution shift，不是训练拟合能力。

### 第二段：基础表征

- V1 证明简单融合不够。
- V2 解决人物区域和 IMU 坐标问题。
- V3 证明时空视觉是主信息源。
- 最终基础主干按模态专门编码，在 token 层用 masked Transformer 融合。

### 第三段：小模型增强

- V24 用参数汤和 INT8 建立部署锚点。
- V52/V57 把复杂教师压缩成小残差与序列学生。
- protected Adapter 限制可训练子空间，避免大参数微调遗忘。

### 第四段：条件化适配

- V114 在有同人 source 时做跨环境适配。
- V127 按监督可用性路由，不学习容易过拟合的置信度阈值。
- unsupported label 回退 V24，unknown date 回退 V57。

### 第五段：最终取舍

- V160/V166 说明结构先验会过拟合采集脚本。
- V164 让 Radar challenger 服从神经 posterior。
- 最终主方案 V127 私榜第 4，84.09 MB，两个提交都 byte-exact 复现。

## 8. 易错题

### Q1：最终神经网络用了六个模态吗？

**答：** 原始数据有六类模态，但最终基础神经主干使用 Depth、Thermal、IR、Skeleton 和 IMU；Radar 原始点不进入主干，只在 V164 中用时间戳做结构分组。

### Q2：V71 是最终 unmatched 专家吗？

**答：** 从代码路径名称看 unmatched 走 V71，但最终 FiLM gate 关闭，输出精确等于 V57。应称为“V71 code path carrying the V57 anchor”，不能说最终标签直接受 V71 FiLM 修正。

### Q3：V127 是否直接在 V114/V57 的 raw 输出上路由？

**答：** 不是。各候选先分别做结构解码，再按 source availability 路由，之后再做 coverage protection 和日期 rollback。

### Q4：V164 是否把 Radar 点云送进 Transformer？

**答：** 没有。它只用 Radar 时间戳形成另一套 round grouping，作为结构 challenger。

### Q5：V166 为什么不用？

**答：** 虽然本地 `90.35%`，但 public `0.88557`，说明重复转移规律没有迁移到测试分布。

### Q6：参数汤是不是五次前向？

**答：** 不是。五个 checkpoint 先在参数空间平均，推理只跑一个融合后的主干。

### Q7：模型是 84 MB，为什么显存 13.49 GB？

**答：** 84.09 MB 是所有资产的磁盘预算；显存还包含解量化后的权重、BF16 激活、视频 batch、中间特征和缓存。

### Q8：同人 source 是否违反跨用户验证？

**答：** 它不是严格 unseen-natural-person 设置，而是同一自然人的 cross-environment transfer。报告已把这部分单独定义和披露；基础 checkpoint 排除目标 person，target 标签不可见。
