# Model Card

## Model Description

Lazyshu is a 40-class multimodal human-activity recognition system developed for the CUHK-X Small Model Track. The base classifier has 64,953,671 parameters; all 14 runtime assets total 84,094,248 bytes.

## Inputs

- Depth, thermal, and infrared video.
- 17-joint 3D skeleton sequences.
- Up to five wearable IMU streams transformed into an 85-feature world-oriented representation.
- Radar timestamps only for the optional V164 structural challenger; raw radar points are not neural inputs.

Missing modalities are removed using explicit masks.

## Architecture

- Shared R(2+1)D-34 visual encoder.
- Skeleton temporal CNN.
- IMU Conv1D + bidirectional LSTM.
- Two-layer, six-head, 192-dimensional masked Transformer fusion.
- INT8-stored parameter soup with BF16 neural compute.
- Compact residual students and protected visual adapters.
- Candidate-specific structural decoding and deterministic routing.

## Intended Use

- Research on compact multimodal activity recognition.
- Reproduction of the disclosed competition solution.
- Study of parameter-efficient adaptation and conservative structural decoding.

## Limitations

- The method was optimized on one competition dataset and may not transfer directly to new sensor layouts or activity taxonomies.
- Same-person-source adaptation assumes labeled recordings of the same natural person in another environment; this is not strict unseen-person generalization.
- Structural priors can overfit acquisition scripts. V160 and V166 demonstrated strong local gains but worse online performance.
- The 84.09 MB constraint is a storage budget, not a guarantee of low peak memory or real-time latency. Measured peak CUDA allocation was 13.49 GB on an A800.
- Raw competition data are not redistributed.

## Reproducibility

Every competition runtime asset has a frozen size and SHA-256, and the primary and secondary submissions were regenerated byte-for-byte during the private reproduction audit. The public repository does not distribute those weights or prediction files.
