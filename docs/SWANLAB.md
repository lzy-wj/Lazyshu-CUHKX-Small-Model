## Public release policy

Raw SwanLab logs are not committed because metadata include absolute server paths, hostname, hardware inventory, and full command lines. The repository includes:

- `swanlab_run_index.csv`: run ID, timestamp, name, status, and online URL.
- `swanlab_summary.json`: aggregate audit statistics.
- Technical report tables and the full version-history document.

If the project is later made public, the README can link to the SwanLab dashboard. This visibility change requires explicit owner approval.
