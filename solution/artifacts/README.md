# Private Runtime Artifacts Not Included

The competition runtime used 14 hashed assets totaling 84,094,248 bytes, including the INT8 base model, YOLO11n cropper, head deltas, protected adapters, compact residual students, and decoder state.

Those artifacts are retained privately and are not part of this code-only release. `../configs/artifact_hashes.json` is preserved as a historical byte-count and SHA-256 inventory.

See `WEIGHTS_NOT_IN_GIT.md` and the repository reproduction notes for the public-release boundary.
