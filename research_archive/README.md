# Historical Research Archive

This directory preserves source code, configurations, README/RESULTS/STATUS notes, and lightweight research records across the experiment lineage.

- Generated checkpoints, predictions, logs, caches, SwanLab binaries, leaderboard snapshots, and public-probe artifacts are intentionally excluded.
- Historical absolute server paths were replaced with `${LAZYSHU_PROJECT_ROOT}` or `${HOME}`.
- This archive documents research evolution; the authoritative runnable release is `solution/` plus the frozen release bundle.
