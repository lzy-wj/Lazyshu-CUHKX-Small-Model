# 高容量多模态 V7 研究结果

日期：2026-09-08。

## 结论

V7 在两个固定跨用户验证折上达到 **76.53% / 83.26%**，按 1,357 条验证片段加权为 **80.03%**。相对 V6 的 75.90% 提升 4.13 个百分点。真实 Kaggle Public 从 V6 的0.73631提升到 **0.82089**（submission ref `56082954`），线上净增8.46个百分点。95%目标仍未达到，不把公开榜泄露方案的分数包装成建模结果。

## 有效改动

| 实验 | Fold 0 | Fold 1 | 结论 |
| --- | ---: | ---: | --- |
| V6，INT8融合+重复解码 | 73.16% | 78.44% | 已提交基线 |
| 32帧 R(2+1)D 视觉主干 | 65.34% | 67.66% | 长时序两折均提升 |
| 16/32帧同架构权重汤，INT8+hflip | 67.18% | 70.64% | 单模型压入两种时间尺度知识 |
| 权重汤+中心75%裁剪四视图TTA | 67.79% | 71.91% | 两折稳定提升，不增加模型大小 |
| 与X3D/统计基座原始融合 | 70.55% | 78.72% | Fold 0选权重，Fold 1原样确认 |
| 环境转移+重复+轮内唯一解码 | **76.53%** | **83.26%** | 加权 **80.03%** |

权重汤固定使用 25% 的16帧多模态 checkpoint 与75%的32帧多模态 checkpoint。Fold 0在候选权重中选择0.75，Fold 1未经重选达到70.64%。部署时只保存一个量化后checkpoint，不保留两个R(2+1)D副本。

## 被否决路线

- 160px R(2+1)D Fold 0为64.72%，不优于32帧路线。
- AdaBN在Fold 0从65.03%升至65.95%，但Fold 1从67.52%降至66.67%，不采用。
- 16帧回放权重汤仅58.13% / 52.77%，说明最终模型必须按32帧部署。
- 类别先验校正、受试者级动作集合筛选和线性堆叠均未跨折稳定，不纳入测试预测。
- 加入全部视觉通道的早期融合与冻结视觉编码器未超过最终权重汤。

## 最终结构

1. YOLO11n生成固定人物窗口，32帧Depth_Color RGB与IR灰度输入R(2+1)D-34。
2. Skeleton由时序CNN编码，IMU由CNN+BiLSTM编码，Transformer在视频、骨架和IMU token间融合。
3. 同架构16/32帧checkpoint做参数插值后按输出通道INT8量化；推理平均原图、水平翻转、中心75%裁剪及其翻转四个视图。
4. 与X3D多模态模型和统计传感器专家融合。按训练场景学习动作转移矩阵，恢复重复轮次后执行带轮内类别唯一约束的beam search。

解码只使用训练标签学习场景转移；测试侧只使用模型概率和原始采集间隔。没有使用测试标签、匿名样本到原数据标签的映射、手工标注或帧号/时间戳到类别映射。
