# 高容量多模态 V6 研究结果

日期：2026-09-07。

## 结论

本轮没有把目标 95% 包装成已完成。当前最佳无测试标签方案在两个固定跨用户验证折上为 73.16% / 78.44%，按 1,357 个片段加权为 75.90%；旧 V3 为 70.52%，本轮提升 5.38 个百分点。官方测试成绩必须以 Kaggle 实际提交为准。

公开榜的 95% 以上不能直接当作可复现建模目标。比赛讨论已确认早期公开仓库曾泄露带标签划分元数据，主办方随后删除；Stage 2 会在新采集数据上复现。因此本项目不使用文件时间戳或帧号匹配训练标签，也不使用任何泄露标签。

## 核心实验

| 实验 | Fold 0 | Fold 1 | 结论 |
| --- | ---: | ---: | --- |
| 旧 V3 完整融合 | 66.87% | 73.90% | 上一轮基线 |
| R(2+1)D-34，随机初始化 | 43.40% | — | 训练 40 轮仍明显不足 |
| R(2+1)D-34，IG65M→Kinetics 初始化 | 61.04% | 63.69% | 外部视频表征显著有效 |
| 同折视觉初始化后融合 Skeleton/IMU | 62.27% | 64.40% | 两折均小幅提高 |
| 上述多模态模型，INT8 + hflip | 64.26% | 65.39% | 量化后 TTA 两折均提高 |
| 可部署全 INT8 原始融合 | 68.56% | 75.18% | 加权 72.00% |
| 原始融合 + 盲重复轮次解码 | **73.16%** | **78.44%** | 加权 **75.90%** |
| Thermal CNN + BiGRU，随机初始化 | 32.67% | 34.75% | Fold 0 选出的融合权重为 0 |

更大的 scratch DSTformer 骨架也未解决泛化：内层验证达到 65.20% / 62.66%，外层未见用户只有 36.96% / 43.55%；强增强 Fold 0 外层也只有 39.42%。这证明当前瓶颈不是“参数还不够大”，而是跨用户表征与视觉细粒度线索。

## 最终结构

1. YOLO11n 为每段 IR/Depth_Color 建立固定人物窗口，取 16 帧、Depth_Color RGB + IR 灰度，输入 4 通道 R(2+1)D-34。
2. 同折先训练视觉模型，再加载视觉权重；Skeleton 使用多流时序 CNN，世界坐标 IMU 使用 CNN + BiLSTM，最终通过 Transformer 与视频 token 融合，并以零初始化残差修正视觉 logits。
3. 与旧 X3D 多模态模型和统计传感器专家融合。全部卷积/线性权重按输出通道对称 INT8，其他浮点张量 FP16。
4. 仅根据原始采集时间间隔恢复无标签动作轮次。训练集 790 个可恢复轮次没有任何轮次内重复类别；Fold 0 选择重复组阈值，Fold 1 原样确认。没有使用测试用户、trial、标签或时间戳到标签映射。

| 资产 | Bytes |

| X3D INT8 | 8,442,631 |

模型资产按十进制计小于 100 MB。R(2+1)D Fold 0 INT8 无 TTA 为 61.20%，原 FP16 保存概率为 61.04%；没有观察到量化精度损失。X3D INT8 两折为 66.26% / 72.62%，同样未低于原模型。

## 边界

外部 IG65M/Kinetics 与 YOLO/SSD 初始化属于主办方讨论中明确允许的小模型预训练路线，但它不再是“全流程随机初始化”候选；随机初始化结果单独保留。公开榜 95% 的早期泄露背景、当前验证 75.90% 与未来官方分数必须明确区分。
