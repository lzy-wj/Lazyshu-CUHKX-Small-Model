# 最终 scratch 多模态候选 v2

## 结论

本轮没有证明“所有视觉 token 直接交给 Transformer”优于 CNN。受控实验表明，保留全部 10×10 空间 token 相对 2×2 池化只有小幅、带不确定性的收益；直接 patch 投影也没有稳定优势。相同用户隔离下，原 CNN+TCN Thermal 单模态达到 28.65%/31.58%，空间 token 编码只有 19.83%/22.22%。

真正稳定的改进来自两点：先独立训练各模态编码器，缓解联合训练时 Thermal/IMU 分支塌缩；再混合两种互补融合。分阶段空间模型相对同架构端到端模型在两折外层均提升，合并提高 2.43 个百分点。

强 CNN 编码器的两种子实验中，自注意力融合为 51.07%，查询式跨模态融合为 49.96%。仅根据每折内层用户选择的 75% 自注意力 + 25% 查询式融合，在缩小训练集的外层验证上达到 51.66%。该比例在完整训练折实验前已冻结。

## 同口径完整训练折结果

| 预测 | 折 0 | 折 1 | 两折合并 | Macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| 原两种子自注意力 | 53.99% | 59.72% | 56.96% | 48.04% |
| 新两种子查询融合 | 53.22% | 59.72% | 56.60% | 47.14% |
| 固定 75/25 混合 | **55.67%** | **60.57%** | **58.22%** | **49.30%** |

固定混合相对原候选提升 1.25 个百分点，两个折都不下降。八位验证用户中七位提高，一位下降 0.52 个百分点；固定模型下的用户聚类 bootstrap 95% 区间为 [+0.50, +2.00] 个百分点。验证折此前已多次用于开发，该区间不包含重新训练方差，也不是官方测试置信区间。

## 全量训练与测试预测

查询融合 seed42/43 分别按折上最佳优化步数重训 9/7 epoch，使用与原最终模型相同的全量 scratch Skeleton、世界坐标 IMU、运动裁剪 Thermal 编码器来源。四个模型均在 3036 个训练片段上重训，未使用测试标签或外部预训练权重。

最终权重为 `[0.375, 0.375, 0.125, 0.125]`，依次对应两个自注意力和两个查询融合模型。四个 FP32 checkpoint 共 43,125,972 bytes；完整包 46,572,136 bytes，低于 100MB。

缓存测试推理与独立原始文件读取均生成 405 条预测，类别完全一致，概率最大差为 0。没有向 Kaggle 提交，官方测试准确率未知，因此不声称达到 95%。
