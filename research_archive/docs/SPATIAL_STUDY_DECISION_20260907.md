# 本轮结论与选型记录

## 已完成的工作

三组架构、两个内外层用户隔离划分、两个随机种子，共 12 次 60 epoch 从零训练全部完成。训练使用 BF16，SwanLab 在线记录。CNN 池化和空间保留组的参数量及初始权重相同；纯 patch 组通过 FFN 宽度匹配参数，总量差异不到 0.4%。

两组 CNN 的空间 token 数分别为每帧 4 和 100；后者没有在 Transformer 前增加空间池化。Patch 组直接投影图像块，没有视觉 CNN 骨干，但传感器分支仍为 CNN/RNN，不应称整个多模态模型为纯 Transformer。

## 结果：有小幅迹象，没有突破证据

| 固定架构 | seed42 外层 | seed43 外层 | 两种子概率平均 | 平均后 macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| CNN 提前池化对照 | 42.67% | 42.59% | 44.66% | 35.61% |
| CNN 保留空间 token | 43.26% | 43.18% | 46.65% | 38.71% |
| 直接 patch Transformer | 40.75% | 42.08% | 44.88% | 36.78% |

空间保留组相对池化组的两种子平均预测提升 1.99 个百分点；八位外层用户的探索性聚类 bootstrap 区间为 [-1.71, +5.08] 个百分点，包含零。两个种子的汇总方向一致，但单种子逐折方向并不都一致；两种子平均后折 0 提升 3.83、折 1 提升 0.28 个百分点，不能声称稳定解决了瓶颈。

两种子平均的全身动作准确率由 72.68% 变为 73.41%，其余 31 类由 32.52% 变为 35.06%，收益主要在后者。但逐类并非普遍提高：拖地从 2/17 正确提高到 9/17，深蹲却从 17/24 降为 9/24。不能只展示改善最大的类别。

直接 patch 组不能证明优于 CNN。结果反对“只要取消池化或去掉 CNN 就会大幅提高准确率”这个简单解释，但不能证明更好的 patch 模型永远无效。

## 为什么不直接宣传 46.65% 是新最佳成绩

三组的表格是固定架构对照，不是根据外层分数选择部署模型。按预先声明的规则，各折根据自己的内层两种子平均选择：折 0 选 CNN 保留空间 token，折 1 选 patch；合并对应外层预测为 46.06%。不因为看见外层结果，就把折 1 换成外层更好的架构。

本轮为了保留内层未见用户，每折实际拟合约 1650–1690 个片段，且没有之前的分阶段编码器预训练。旧的 56.96% 模型使用更多拟合片段、不同训练流程，不能作本轮受控基线；本轮也没有证明它优于旧最终候选。

旧的 `outputs/final_scratch_input/` 与 zip 文件没有替换，原始 payload hash 和 zip SHA256 已重新核对一致。官方测试集没有新提交，未知官方准确率。

## 更有价值的诊断：视觉敏感性仍然很低

对 seed42 的内层验证做推理屏蔽，CNN 保留空间 token 组：

| 操作 | 折 0 accuracy | 折 1 accuracy |
| --- | ---: | ---: |
| 原始模型 | 46.74% | 52.78% |
| 屏蔽 Thermal | 45.73% | 51.90% |
| 屏蔽 Skeleton | 19.25% | 21.05% |
| 屏蔽 IMU | 43.56% | 45.91% |

视觉 token 增加 25 倍后，预测对 Thermal 屏蔽仍只有约一个百分点的敏感性，而骨架屏蔽影响约 27–32 个百分点。**这比“参数还不够大”更具体，但仍不是融合失败的因果证明。** 视觉分支本身弱、与传感器信息冗余、训练过程偏向容易模态、输入细节不足，都可能产生这个现象。

注意力诊断也不支持“视觉 token 多，所以训练后一定被视觉占满”：CNN 保留组折 1 的 Thermal token 虽占 memory 约 98%，最后一层平均 attention mass 只有约 7.6%。网络已学会改变分配。不能把 token 比例直接当作实际注意力，也不能把注意力当作因果重要性。

重放相对保存的预测至多改变 1 个类别；显式提取注意力因浮点执行路径改变，至多再改变 2 个类别。这里没有宣称逐比特一致。屏蔽是推理分布干预，不是重新训练消融。

## 下一步应检验什么

1. **先做视觉单模态的匹配训练。** 使用同样的内层用户划分，比较视觉分支自身能否区分相似动作。不能仅靠融合模型的低敏感性判定编码器不行。
2. 如果单模态有辨识力、融合后却没有增益，再比较经过同一拟合集独立训练的编码器与端到端初始化，明确验证学习失衡。初始化来源必须未见内层和外层用户。
3. 如果单模态也弱，先验证原图分辨率、运动阶段、IR/Depth 的互补信息，再考虑加深或加宽模型。

以上是由本轮证据决定的后续路线，尚未运行，不与已经完成的 12 次实验混写。当前保留旧提交候选，不承诺达到 95%，也不把小幅验证波动包装成最终成功。
