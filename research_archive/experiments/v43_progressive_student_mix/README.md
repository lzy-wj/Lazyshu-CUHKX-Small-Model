# V43 Progressive Student Mix

V43 averages 90% V24 hard-adapted warm-60 soup probabilities with 10% hard-
adapted progressive-160 student probabilities. The ratio is selected on Fold 0
where it scores `552/652`, two rows above the reference. Fold 1 is evaluated
once blind.

If promoted, the second student will be represented as a low-rank delta from
the shared R(2+1)D backbone rather than a second full checkpoint.
