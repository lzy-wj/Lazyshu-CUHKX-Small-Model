# V107 Square-Root Class Balance

V107 tests one data-objective change motivated by V104's remaining errors. The
weakest fine-grained object actions are also among the least represented
classes, while the acquisition protocol heavily repeats common locomotion
classes. V107 applies inverse square-root class weighting to the proven V23
warm masked-modality-distillation recipe.

The square root is fixed before validation as the conservative midpoint
between empirical sampling and full inverse-frequency reweighting. Architecture,
initialization, augmentations, optimizer, epochs, and both user-isolated folds
remain unchanged. No weight sweep or class-specific validation tuning is used.
