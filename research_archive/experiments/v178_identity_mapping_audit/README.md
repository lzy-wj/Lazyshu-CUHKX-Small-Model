# V178 Identity Mapping Audit

A label-free audit compared robust skeleton bone-length signatures across
training users and test acquisition dates. The expected paired users were not
nearest neighbours consistently: ranks for 6->16, 7->17, 8->18, and 9->19 were
8, 9, 5, and 3 under global signatures. Action-matched signatures improved the
ranks to 3, 4, 2, and 2, but still did not identify the pair reliably.

The signal is too sensitive to pose estimation, view angle, and action mix.
No test routing or candidate is produced from this audit.
