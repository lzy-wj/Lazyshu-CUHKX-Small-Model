# V104 Domain-Gated Adapters

V104 keeps V89 unchanged outside the domains where compact adapters have
independent two-fold evidence. The fixed routing is:

- unmatched high-environment rows: equal V89, V97 dual, V98 cross, and V99
  refreshed-cross probabilities;
- paired low-environment rows: equal V89 and V97 dual probabilities;
- paired high-environment rows: V89 probabilities only.

The local protocol uses users `23/22` for the unmatched high environment and
users `8/7` for the paired low environment. Full-data deployment replaces the
fold-specific target adapters with two test-pseudo adapters trained from the
same full V24 soup. Kaggle is never called automatically.
