# V120 Retrieved-Donor Adapters

V120 targets the unmatched high-environment domain, the largest remaining
generalization bottleneck. A strict label-free script-margin retrieval made
before this experiment selects source user 20 for Fold0 target 23 and source
user 21 for Fold1 target 22. The V113 adapter recipe then combines donor true
labels with target pseudo labels. This tests whether script similarity can
replace unavailable same-person supervision.
